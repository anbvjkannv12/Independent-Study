## 預期問題與回答要點

| 問題 | 回答要點 |
|---|---|
| AUC 0.52 跟亂猜差不多，為什麼說有訊號？ | 有些設定通過 block bootstrap/Holm 的訊號關卡，但效果很小；統計訊號不等於交易價值。 |
| 為什麼不用更複雜模型？ | LSTM、Transformer 都試過，沒有穩定勝過 XGBoost；瓶頸較像資料資訊量。 |
| 有沒有資料洩漏？ | 時間順序切分、24 列 purge、門檻只用 validation；多視窗驗證 V1～V8 PASS。 |
| BTC 早期選 Transformer，現在為何說沒有優勝模型？ | 早期依平均 AUC 選擇；後續嚴格比較顯示差距在雜訊範圍內。 |
| 為什麼不做 Stacking？ | 基礎模型表現不穩定且高度相關，融合弱模型不太可能穩定改善。 |
| 1h 比較好，為何不改用 1h？ | 只有 XRP 通過完整判定，未達至少 2 幣種門檻；且可能是短期反轉，需新資料驗證。 |
| 研究有什麼用？ | 提供可信負結果與可重現框架，避免高估 K 線方向預測能力。 |
| 如果重來會怎麼做？ | 更早保留完全未使用的獨立測試期，並更早建立預先登記。 |
