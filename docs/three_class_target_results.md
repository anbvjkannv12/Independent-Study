## 限制

- test 期間和先前多個實驗重疊，不是獨立確認。
- 固定 k = 0.002 讓各幣種的不交易比例不同。
- 只扣固定手續費，沒有滑價、資金費率、部位上限。
- 4h 標籤逐小時重疊，交易不是互相獨立。
- 只測 XGBoost。
